# Security Policy

## Reporting a vulnerability

Email [contact@zlatanstajic.com](mailto:contact@zlatanstajic.com) privately with
security concerns. Do not publish sensitive details in public issues or pull
requests.

Include the affected revision, operating system and Java version, steps to
reproduce, and the potential impact. Remove credentials and personal information
from examples and logs.

The maintainer will review the report and coordinate any fix and disclosure with
the reporter. There is no guaranteed response time or published security support
schedule for historical revisions. Please allow time for a fix before sharing
vulnerability details publicly.
